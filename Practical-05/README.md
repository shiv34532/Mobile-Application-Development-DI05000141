# Practical 05 — Event Handling using Button and EditText

**Unit:** UI Design and Event Handling | **CO:** 2 | **Hrs:** 2

## Aim
To implement event handling in Android applications using UI elements such as Button and EditText.

## Theory
Event handling in Android is done via listeners like `setOnClickListener`, `addTextChangedListener`, `setOnFocusChangeListener`, etc. These respond to user interactions such as clicks, text changes, and focus changes.

## Code
See [src/EventHandlingActivity.java](./src/EventHandlingActivity.java) and [layout/activity_event.xml](./layout/activity_event.xml)

## Output
Typing in the EditText live-updates a TextView below it (character count), and clicking the Button shows a Toast with the entered text.
