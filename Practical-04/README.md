# Practical 04 — Calculator UI using Different Layouts

**Unit:** UI Design and Event Handling | **CO:** 2 | **Hrs:** 2

## Aim
To design a Calculator user interface in Android using different layouts such as ConstraintLayout, LinearLayout, RelativeLayout, and FrameLayout.

## Code
See [layout/activity_calculator.xml](./layout/activity_calculator.xml) — a grid-style calculator UI built with nested LinearLayouts (rows of number/operator buttons + a result display).

## Output
A calculator screen with a display TextView on top and a grid of digit/operator buttons below (0-9, +, -, ×, ÷, =, C).
