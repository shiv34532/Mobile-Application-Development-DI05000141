# Practical 09 — RecyclerView and Adapter

**Unit:** UI Design and Event Handling | **CO:** 2 | **Hrs:** 2

## Aim
To develop an Android application that displays a list of items using RecyclerView and Adapter.

## Theory
`RecyclerView` is a more flexible, efficient version of ListView. It requires a `LayoutManager`, an `Adapter`, and a `ViewHolder` to recycle item views for performance.

See [layout/activity_recyclerview.xml](./layout/activity_recyclerview.xml), [layout/item_student.xml](./layout/item_student.xml), and [src/StudentAdapter.java](./src/StudentAdapter.java), [src/RecyclerViewActivity.java](./src/RecyclerViewActivity.java)

A scrollable list of student names and roll numbers rendered efficiently using RecyclerView.
