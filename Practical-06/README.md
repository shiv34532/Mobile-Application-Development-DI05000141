## Aim
To implement Login, Registration and Calculator activities using event handling (combining Practicals 02–05 into fully functional activities).

## Code

- [src/RegisterActivity.java](../Practical-03/src/RegisterActivity.java) — click listener validates registration form.
- [src/CalculatorActivity.java](./src/CalculatorActivity.java) — full working calculator logic.
