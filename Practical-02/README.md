# Practical 02 — Login Page UI using Different Layouts

**Unit:** UI Design and Event Handling | **CO:** 2 | **Hrs:** 2

## Aim
To design a Sign in/Login page user interface in Android using different layouts such as ConstraintLayout, LinearLayout, RelativeLayout, and FrameLayout.

## Theory
- **ConstraintLayout:** Flexible layout using constraints between views; ideal for complex, flat view hierarchies.
- **LinearLayout:** Arranges children in a single row or column.
- **RelativeLayout:** Positions children relative to each other or the parent.
- **FrameLayout:** Stacks children on top of each other; used for single-view/overlay designs.
