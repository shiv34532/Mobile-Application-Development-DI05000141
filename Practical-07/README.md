# Practical 07 — ListView and Spinner with Event Handling

**Unit:** UI Design and Event Handling | **CO:** 2 | **Hrs:** 2

## Aim
To design Android applications using ListView and Spinner and implement appropriate event handling for both.

## Theory
- **ListView:** Displays a scrollable list of items, backed by an `ArrayAdapter` or custom adapter.
- **Spinner:** A dropdown selection widget, similar to a combo box.

## Code
See [layout/activity_listview_spinner.xml](./layout/activity_listview_spinner.xml) and [src/ListSpinnerActivity.java](./src/ListSpinnerActivity.java)

## Output
A Spinner lets the user pick a fruit; a ListView below shows a list of items, and tapping any item shows a Toast with the selected item's name.
